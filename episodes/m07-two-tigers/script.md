# M07 · Are You Sleeping, Bruno? 两只老虎（英文儿歌版）

> 2026-11-13。用户看完 m06 小蝌蚪第四版：「剧本太无聊了，爆款视频里面情绪点、爆点这些都没有……我觉着小星星那一期挺好的」，所有成片都已发布，小星星表现最好。
> 用户在卡片上选《两只老虎》（B 站头部 贝乐虎 227.6 万，11-05 查，见共享文件夹 song-topics-2026-11.md），补充：「做这个的话，要有儿歌」。
> 模式：m03 老儿歌对话版，但**儿歌唱的比例加大**：全片三段演唱（钩子、叫醒、片尾），台词段用乐器弹原旋律、固定电平。**主角是两只小老虎**（11-13 用户：「为什么歌曲是两只老虎，主角是别的动物」）：Tigo（橙色小老虎、尾巴长）和 Mimi（浅橙小老虎、圆耳朵），集内 characters.json 新角色；睡大觉的是系列的 Bruno。日系手绘简洁版。
> 关键帧 + 张嘴帧（说话中途换图也要张嘴帧）；H3 只给两段动作：p3 呼噜把 Tigo 吹翻、p6 Bruno 跳起来尾巴弹回。目标 45 秒，上限 50。

## 版权
- 旋律：法国民歌 Frère Jacques（18 世纪），公有领域。
- 英文词：传统 "Are you sleeping, Brother John? Morning bells are ringing, ding, dang, dong" 是公有领域；我们把 Brother John 换成 Bruno。
- 第一段和片尾的英文词是我们按中文「两只老虎」的意思自己写的（中文原词无作者，我们不用中文词）。

## 为什么这样写（照 m03 公式）
| m03 小星星为什么好 | m07 对应 |
|---|---|
| 家长一听就熟的旋律 | 两只老虎，开口就是这个调，而且唱的就是那个梗：一个没耳朵、一个没尾巴，真奇怪 |
| 有急事 | Tigo 的尾巴不见了，急哭了（不画眼泪） |
| 歌就是解法 | 尾巴被睡着的 Bruno 压住了，叫不醒，大家一起唱 Are you sleeping 把他唱醒 |
| 一起喊的高潮 | 宝宝隔屏跟唱，ding, dang, dong 一声比一声大 |
| 大个子出糗 | Bruno 一个呼噜把 Tigo 吹翻；醒来坐在尾巴上还不知道 |
| 回扣的彩蛋 | Bruno 又困了，这次躺在 Mimi 的耳朵上 |

## 今日单词
tail 尾巴 · ears 耳朵 · wake up 醒醒

## 情绪曲线
欢快赛跑（唱）→ 撞进草丛、惊慌（没尾巴！）→ 好笑（Mimi 帽子盖住耳朵）→ 着急（尾巴在 Bruno 屁股底下，叫不醒）→ 爆笑（呼噜吹翻）→ 一起唱、越唱越响（高潮）→ 惊喜 + 解气（尾巴"啵"地弹回来）→ 暖（Sorry / It's okay）→ 彩蛋笑。

## 分页

| 页 | 画面（关键帧） | 台词 / 演唱 | 大字 / 音效 |
|---|---|---|---|
| hook（唱） | Tigo 和 Mimi 在林间小路上赛跑，一前一后 → 越跑越快 → 一头扎进灌木丛，叶子炸开 | 演唱：`Two little tigers, two little tigers, run so fast, run so fast!` | 大字「两只老虎，英文版来了！」；扎进去"噗" |
| p1 | Tigo 从草丛里钻出来，回头看屁股——尾巴不见了；Mimi 头上扣着一顶橡果帽，盖住了两只圆耳朵 | 演唱：`One has got no ears, one has got no tail. How strange! How strange!` | 大字「谁的尾巴不见了？」 |
| p2 | Tigo 急得转圈；Mimi 把帽子一掀，圆耳朵弹出来 | **pip**: `My tail! Where is my tail?` ／ **bun**: `Huh? Oh! My ears!` | 耳朵弹出"啵" |
| p3 | 两人顺着地上的印子找过去：大树下 Bruno 四仰八叉睡大觉，屁股底下露出一截一截橙黑条纹的老虎尾巴（和 Tigo 明显分开）（观众先看到） | **pip**: `There! Bruno! Wake up!` | 呼噜声 |
| p4（H3） | Tigo 使劲拽尾巴；Bruno 一个大呼噜，把 Tigo 吹得骨碌碌滚出去 | **bruno**（打呼）: `Zzz... HONK!` | 滚出去"咕噜噜"；大字「叫不醒！」 |
| p5 | Mimi 灵机一动、竖手指，再转身对镜头招手 | **bun**: `I have an idea! Let's sing!` ／ **bun**: `Sing with us!` | 叮 |
| p6（唱） | 三格递进：两人凑到 Bruno 耳边唱 → Bruno 耳朵一抖 → 一只眼睁开 | 演唱：`Are you sleeping, are you sleeping, Bruno? Bruno? Morning bells are ringing, ding, dang, dong!` | 大字「宝宝一起唱，叫醒 Bruno！」；ding dang dong 一声比一声大，配钟声 |
| p7（H3） | Bruno 一下子弹坐起来，尾巴从屁股底下"啵"地弹回 Tigo 身上 | **bruno**: `I'm awake!` ／ **pip**: `My tail!` | 弹回"boing"；音乐最高点 |
| p8 | Bruno 不好意思挠头；Tigo 抱着尾巴笑 | **bruno**: `Sorry, Tigo!` ／ **pip**: `It's okay!` | 三个一起笑（笑声走音效层） |
| p9 彩蛋 | Bruno 打个大哈欠躺下——这次躺在 Mimi 的耳朵上 | **bun**: `My ears!` | 滑稽"咚" |
| 复习（唱） | 复用 p2 / p7 / p6 | 演唱：`Now we've got our ears, now we've got our tail. Hooray! Hooray!`；复习词 tail · ears · wake up 各说一遍 | |

台词 11 句（不算唱），每句 ≤5 词。演唱三段约 8 + 6 + 8 秒。

## 音乐和演唱
- 乐器版原旋律（木琴 + 钢片琴 + 拨弦，96–110 BPM，轻快）全片一个固定电平，台词时不压、不开关（m03 规则）。
- 演唱：ElevenLabs Music 出温暖、笑着唱的童声/女声带小朋友跟唱，出 3 版；按 m03 做法分轨取人声、逐音节修到原调（`out/m03/make_vocal.py`），听写校对歌词。先做试听页让用户挑一版再出片。
- 叫醒段 ding, dang, dong 每次更响，配真实钟声；Bruno 醒的那一下音乐一个上行刮奏。

## 常理和安全
- 尾巴被压住、拽不出来：Tigo 不疼（表情是急不是疼），Bruno 是不知道，不是欺负。
- 呼噜吹翻是软软地滚到草地上。
- 橡果帽是道具，第一页前在路边露一下（hook 里 Mimi 跑过时顺手戴上）。
- 不画眼泪；大圆眼；主体居中、画满到底；只有三个角色。
