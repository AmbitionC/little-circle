# 角色设计方法（2026-10-30）

> 用户原话："避免用那种没有特色的动物形象来做角色。比如疯狂动物城里面的动物形象，都有自己鲜明的特征，比如尼克狐，兔子警官，闪电那些，都有非常明确的记忆点。这个非常关键。"
> 学方法，不照搬角色。角色表和出图原文在 [series/characters.md](../series/characters.md)。

## 升级前的问题

- 7 张参考图全是正面站立、张嘴笑、小手举胸前，比例一样。把颜色去掉只看剪影，除了耳朵基本分不出来，能区分的只剩围巾、背心这些配饰。
- 性格写的是形容词（"害羞、老实"），没有"想要却得不到"，写不出戏。
- 撞性格：Bun 和 Bo 都慢；Pip、Dot、Fern 都跑得快；Nutty 冲动、Wiggles 停不下来。
- 一半角色没有口头禅。

做对了的两个：Hazel "一紧张刺就嘭地竖起来"、Bruno "肚子软得像蹦床"，就是下面说的情绪器官和身体笑点。

## 从疯狂动物城学的四条

1. **物种印象 + 反差**：在大家对这种动物的印象上反着来，一句话就记住。最慢的树懒在车管所上班还叫 Flash；最弱小的兔子当警察；能托在手心的鼩鼱是黑帮老大；猎豹是爱吃甜甜圈的胖前台。
2. **真实习性做表演**：动画团队专门研究真实动物，比如树懒有多慢、兔子开心时的"蹦跶"（binky）都放进了角色动作里。来源：[5 Minutes for Mom](https://www.5minutesformom.com/zootopia-story-and-animal-development/)。
3. **真实体型比例**：导演 Byron Howard 说体型坚决不作弊，"95 只老鼠叠起来才等于一只长颈鹿"。大小对比本身就是笑点和冲突。来源：[Screen Rant](https://screenrant.com/zootopia-directors-interview-characters/)。
4. **一个会说话的身体部位**：Judy 的耳朵，难过就耷拉、警觉就竖起。台词还没说，孩子已经看懂情绪。

## 低龄动画补的三条

- **形状语言**（Bluey 美术指导）：圆＝友好柔软，方＝稳当可靠，三角＝尖锐有劲。每个角色主形状选一个。来源：[Creating Bluey: Tales from the Art Director](https://goodsniff.substack.com/p/creating-bluey-tales-from-the-art-891)。
- **专属声音和那句话**：Peppa 一家都会哼哼，George 永远抱着恐龙喊 "Dinosaur!"。2–3 岁先记声音和那句话。
- **特征反复点名**：Gruffalo 每次出场都点一遍"可怕的獠牙、可怕的爪子"。我们的角色出场也固定亮出同一个标志。

## 不学的

疯狂动物城的反差是给大人看的社会讽刺（偏见、黑帮），2–3 岁看不懂。我们只取**身体层面、生活层面**的反差：大的怕小的、该快的偏慢、浑身是刺却想要抱抱。宝宝看得懂，家长觉得有梗。也不碰它的具体角色：Fern 是狐狸，但走"藏不住心事"，和尼克的狡猾正好反着。

## 新角色怎么设计

1. 写齐六件套（见角色表）：反差、剪影钩子、情绪器官、口头禅 + 招牌动作、想要、小毛病。
2. 反差优先从真实动物习性里找（松鼠会忘记埋起来的坚果、猫头鹰能转头约 270 度、浣熊在水里搓食物、海獭揣着喜欢的石头），家长看了会心一笑。
3. 和现有角色比一遍：性格、口头禅、主形状、体型档位不能撞。
4. 剪影测试：把参考图涂成纯黑，和其他角色放一排，还能认出来才算过。
5. 英文外形描述里写进夸张部位，`POSES` 写招牌姿势，`FACES` 写三个表情，再出参考图和设定图。
