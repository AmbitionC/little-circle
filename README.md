# 栗栗学英语 · 副业项目总纲

> 账号：抖音 / 小红书 / 视频号「栗栗学英语」。主角是小松鼠栗栗（Nutty），系列名「森林小伙伴」。

> 当前状态：**M1 进行中**（2026-10-26 ～ 2026-11-22），见 [milestones/M1-2026-11.md](milestones/M1-2026-11.md)

## 一句话

先用 AI 辅助的原创英语启蒙绘本做短视频，把家长吸引过来。再把他们留在粉丝群和微信里，卖电子绘本和学习计划。跑通之后，再做自己的绘本播放器。

## 为什么这么做（调研结论，详见 [docs/research-2026-10.md](docs/research-2026-10.md)）

- **家长付费的核心是绘本。** 但"名牌书单 + 低价"这个组合只有盗版做得到。搬运版权内容的资源平台风险很高（民事连带赔偿，严重的还有刑事责任），我们不碰。
- **正版名牌书授权，个人副业扛不住。** 电子版权按年付费，一本从几千到几十万元，热门书系常被大平台独家拿走。
- **原创路线已经有人跑通。** 抖音个人号"嘟嘟英语绘本馆"做原创英语启蒙绘本，107 万粉丝，通过橱窗卖电子书、建粉丝群，还有自己的播放器。
- **自研绘本是自己的资产。** 有了 AI，一本绘本的制作成本降到几十元。

## 七条原则（来自 life-teachers 知识库里的老师观点）

1. **先验证、再投入**：按四个阶段走：试探定位 → 市场校验 → 产品打磨 → 放大。没验证之前，不加人、不投流、不做 App。
2. **第一个目标是完成一次"一买一卖"**，而不是涨粉。
3. **需求优先**：先做已经被验证的题材（2–4 岁认知词汇），再谈创新。
4. **先建立信任**：先免费给价值，再卖东西；私域靠服务留人。
5. **守住合规红线**：不搬运版权内容，不在平台外导流，AI 生成内容要标识，不让孩子出镜。
6. **主业不动**：时间和预算设上限；判据先写死，到期按数据决策。
7. **做小做精**，给自己两年时间。

## 路径

| 阶段 | 要验证什么 | 产品形态 |
|---|---|---|
| **M1 试探定位（1 个月）** | 找到能留住人的内容形式，完成第一次付费 | 短视频 + 打印包 |
| M2 市场校验 | 稳定起量，在平台内成交 | 橱窗电子书、粉丝群打卡 |
| M3 产品打磨 | 复购和长期服务 | 小程序绘本播放器、30 天学习计划 |
| M4 放大 | 投流、App、系列化 | — |

## 怎么生产

**分工：**
- 剧本和分镜：Claude 按系列规范写。
- 画面：GPT 出图。
- 开头 5 秒钩子：可灵，用首尾帧生成。
- 其余部分：用 [tools/storybook-video](tools/storybook-video/) 做成动态绘本（运镜、立体视差、逐词高亮字幕）。
- 配音、音效、背景音乐：ElevenLabs（流程和交付标准见 [docs/elevenlabs-workflow.md](docs/elevenlabs-workflow.md)）。

**成本**：每条视频约 12–20 元；全程用可灵约 90 元。

## 引流与私域

**三层漏斗：**
1. **公域获客**：抖音为主，小红书发图文、视频号同步。
2. **平台内私域**：粉丝群、橱窗。
3. **微信私域**：视频号、公众号、小程序、企业微信。

不同平台之间靠统一的品牌名衔接。**抖音、小红书上不放微信号或二维码，包括谐音和暗号。**
